# Natural Language Processing Specialization

Материалы специализации **Natural Language Processing Specialization** от **DeepLearning.AI** на платформе Coursera.

🔗 [https://www.coursera.org/specializations/natural-language-processing](https://www.coursera.org/specializations/natural-language-processing)

В папке собраны:
- сертификаты о прохождении специализации
- конспекты по всем 4 курсам

Конспекты составлены по **субтитрам лекций**, **личным заметкам** и структурированы с помощью **ChatGPT**.

## Содержание специализации

Специализация посвящена современным методам обработки естественного языка (**NLP**) и состоит из 4 курсов: 

1. **Natural Language Processing with Classification and Vector Spaces**  
2. **Natural Language Processing with Probabilistic Models**  
3. **Natural Language Processing with Sequence Models**  
4. **Natural Language Processing with Attention Models**
