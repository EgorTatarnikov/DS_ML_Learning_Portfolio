## Содержание специализации

Специализация посвящена современным методам обработки естественного языка (**NLP**) и состоит из 4 курсов: 

1. **Natural Language Processing with Classification and Vector Spaces** — вводит фундамент классического NLP и базовую логику ранних pipeline: текст → предобработка → векторное представление → модель → оценка качества, то есть показывает, как превратить текст в признаки и обучить классификатор.

2. **Natural Language Processing with Probabilistic Models** — переводит NLP от признакового подхода к вероятностному и отвечает на вопрос, как моделировать язык и текст через вероятности, используя n-grams, language models, smoothing и HMM.

3. **Natural Language Processing with Sequence Models** — делает следующий шаг после probabilistic NLP и вместо моделирования текста через короткие вероятностные зависимости учит представлять последовательность как динамическое состояние, которое обновляется при чтении каждого нового токена.

4. **Natural Language Processing with Attention Models** — завершает эту эволюцию, отказываясь от идеи протаскивать весь контекст через рекуррентное скрытое состояние, и переходит к механизму attention, где модель напрямую выбирает, на какие элементы входа нужно смотреть при вычислении представления каждого токена.
