# Data Science и Machine Learning — учебное портфолио

Репозиторий представляет собой **учебное портфолио** по направлениям **Data Science, Machine Learning и Python** и содержит:
- сертификаты и дипломы о прохождении курсов и интенсивов,
- учебные и практические проекты,
- конспекты и личные заметки.
