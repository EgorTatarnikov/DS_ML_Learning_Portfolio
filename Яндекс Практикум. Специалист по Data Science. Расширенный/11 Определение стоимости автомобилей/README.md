## Описание проекта
В рамках проекта разработана модель машинного обучения для предсказания рыночной стоимости подержанных автомобилей на основе их технических характеристик и информации из объявлений.

## Цель проекта
Построить модель, которая:
* качественно предсказывает рыночную стоимость автомобиля (RMSE < 2500),
* быстро обучается,
* обеспечивает высокую скорость предсказания,
* может быть использована в сервисе автоматической оценки стоимости автомобилей.

## Результаты
Обучены и сравнены несколько моделей: Linear Regression, Random Forest, CatBoost, LightGBM

Лучшие результаты показали модели градиентного бустинга.

Модель LightGBM продемонстрировала оптимальный баланс между качеством предсказания (RMSE ≈ 1680), временем обучения и скоростью предсказания и была выбрана как финальная модель.

Также протестировано обучение CatBoost на GPU, что позволило сократить время обучения почти в 3 раза.

## Рекомендации
Для использования в сервисе автоматической оценки стоимости автомобилей рекомендуется использовать модель LightGBM.
При работе с большими объёмами данных целесообразно обучение проводить на GPU.
Для дальнейшего улучшения качества модели можно:
- добавить новые признаки(количество владельцев, объем двигателя),
- провести инжиниринг признаков (редкость модели, пробег на год эксплуатации),
- применить более глубокий подбор гиперпараметров.
