## Описание проекта
В рамках проекта разработана нейронная сеть на PyTorch для прогнозирования температуры поверхности звёзд на основе их наблюдаемых характеристик.

## Цель проекта
Построить регрессионную модель с использованием PyTorch, способную предсказывать температуру звезды с высокой точностью на основе её физических характеристик.<br>
Целевая метрика: RMSE < 4500.

## Результаты
* Протестированы разные комбинации признаков, методы масштабирования и кодирования.
* Наилучшей моделью оказалась нейросеть с двумя скрытыми слоями и функцией активации LeakyReLU.<br> RMSE на тестовой выборке: 3753.
* Для уменьшения переобучения использовались L2-регуляризация в оптимизаторе Adam и Dropout. 
* Проведен перебор Dropout и размера батча. Введение Dropout не улучшило метрики модели.<br> Наилучшая конфигурация: Dropout=0.0, Batch size=64.

## Рекомендации
Для улучшения предсказательной способности модели:
* Увеличить объём обучающих данных;
* Ввести новые признаки:
  * результаты спектрального анализа с длинами волн основного потока излучения,
  * расстояния до звезд для оценки эффекта Доплера.

## Приобретенные навыки
* Работа с PyTorch и построение нейронных сетей для задач регрессии.
* Настройка оптимизации и регуляризации: Adam с L2-регуляризацией и подбор Dropout.
