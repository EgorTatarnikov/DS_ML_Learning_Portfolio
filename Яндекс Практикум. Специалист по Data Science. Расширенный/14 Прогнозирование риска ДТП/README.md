## Описание проекта
В рамках проекта проведён анализ данных о ДТП и разработана модель машинного обучения для прогнозирования риска ДТП по вине водителя. Исследование выполнено в интересах сервиса каршеринга и направлено на повышение безопасности клиентов, а также снижение потенциального ущерба автопарку.

## Цель проекта
Построить модель, способную предсказывать вероятность ДТП по вине водителя на основе характеристик транспортного средства, дорожной ситуации и состояния водителя.

## Результаты
* Целевой признак «Вина водителя» слабо коррелирует с другими признаками.
* Точность предсказания обученых моделей невысокая. Лучшей моделью стала **LGBMClassifier** с метрикой **ROC-AUC = 0.713**.
* Создание надёжной системы оценки риска ДТП по вине водителя на основе текущих данных невозможно.

## Рекомендации
Для увеличения точности модели предлагается:
* Добавить в датасет все поездки, а не только аварийные, чтобы оценивать относительную аварийность маршрутов;
* Включить информацию о водителях (стаж, количество ДТП за период и др.);
* Добавить другие факторы, известные до начала поездки и потенциально влияющие на риск;
* Рассмотреть возможность изменения целевого признака — прогнозировать вероятность ДТП в целом, а не только по вине водителя.

## Приобретенные навыки
