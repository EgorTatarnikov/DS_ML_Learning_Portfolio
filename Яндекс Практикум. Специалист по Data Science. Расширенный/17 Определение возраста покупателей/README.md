## Описание проекта
В проекте решается задача компьютерного зрения — определение приблизительного возраста человека по фотографии.<br>
Такая система может использоваться в прикассовой зоне супермаркета для анализа возрастных групп покупателей и контроля соблюдения возрастных ограничений при продаже акцизных товаров.

## Цель проекта
Разработать модель машинного обучения, которая по фотографии человека сможет определять его возраст с приемлемой точностью.<br>
Целевое требование проекта — **MAE < 8 лет**.

## Результаты
* Проведён исследовательский анализ датасета из 7591 изображения людей.
* Изучено распределение возрастов, выявлены особенности и потенциальные источники ошибок.
* Подготовлены данные и реализована аугментация изображений для повышения устойчивости модели.
* Построена и обучена **нейросетевая модель на базе ResNet50** с использованием предобученных весов.
* Итоговое качество модели: **MAE ≈ 7 лет**, что соответствует требованиям проекта.

## Рекомендации
Модель может использоваться для:
* анализа возрастных групп покупателей;
* персонализации предложений и маркетинговых акций;
* дополнительного контроля соблюдения возрастных ограничений при продаже алкогольной и табачной продукции.

Для повышения точности предсказаний:
* увеличить размер обучающего датасета;
* использовать другие архитектуры (VGG-16, EfficientNet);
* выравнивать положение и масштаб лица (face alignment);
* применять дополнительные методы регуляризации и аугментации;
* использовать ансамбль моделей (итоговый возраст = среднее нескольких моделей).
