## Описание проекта
В рамках проекта разработан прототип системы поиска изображений по текстовому описанию. Пользователь вводит краткое описание сцены, а система возвращает наиболее релевантные изображения из базы данных.

## Цель проекта
Создать модель, которая будет определять степень соответствия текстового описания и изображения.<br>
На основе этой модели реализовать функцию поиска наиболее релевантного изображения по текстовому запросу.

## Результаты
* Проведён исследовательский анализ данных и объединены несколько источников разметки (экспертные и краудсорсинговые оценки).
* Реализована очистка данных в соответствии с юридическими требованиями.
* Опробованы и сравнены разные методы векторизации текста и изображений.
* Подготовлены объединённые векторы текстов и изображений для обучения модели.
* Обучены и протестированы две модели:
  * Линейная регрессия;
  * Полносвязная нейронная сеть.
* Лучший результат показала **полносвязная нейронная сеть с метрикой MAE = 0.1694**.
* Реализована функция поиска изображения по текстовому описанию и проведено визуальное тестирование модели.
* Результаты показали, что разработанный подход способен успешно находить релевантные изображения по текстовым запросам.

## Рекомендации
Для повышения качества поиска можно рассмотреть следующие улучшения:
* Увеличить обучающую выборку в части фотографий с точными описаниями, где оценки экспертов будут высокими;
* Использовать мультимодальные модели (например CLIP), которые обучены сопоставлять текст и изображения в едином пространстве признаков.

## Приобретенные навыки
* Векторизация текстовых данных (TF-IDF, Word2Vec, all-MiniLM-L6-v2).
* Векторизация изображений (ResNet50, ResNet18).
* Реализация MVP на основе обученной модели.
