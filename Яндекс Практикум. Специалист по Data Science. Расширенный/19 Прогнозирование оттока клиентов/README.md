## Описание проекта
Оператор связи сталкивается с проблемой оттока клиентов.<br>
В рамках проекта была разработана модель машинного обучения, позволяющая заранее выявить клиентов с высоким риском расторжения договора на основе данных об услугах, платежах и характеристиках абонентов.

## Цель проекта
Построить модель, прогнозирующую вероятность ухода клиента.<br>
Основная метрика качества — **ROC-AUC ≥ 0.85**.

## Результаты
* Проведен исследовательский анализ данных и сформирован портрет клиента с высокой вероятностью ухода.
* Обучены и сравнены несколько моделей: **RandomForestClassifier**, **LGBMClassifier** и **KerasClassifier**.
* Лучшую предсказательную способность показала **LGBMClassifier** с метрикой **ROC-AUC = 0.908** на тестовой выборке.
* Наиболее важными признаками для прогноза оказались: 
  * длительность контракта,
  * общие расходы клиента,
  * ежемесячные расходы,
  * наличие интернет-подключения.

## Рекомендации
**Бизнесу:**
* Использовать модель для выявления клиентов с высоким риском расторжения договора.
* Предлагать таким клиентам **персональные предложения**, **промокоды** и **специальные условия**.
* Переводить клиентов на **помесячную оплату**, чтобы снизить риск расторжения договора.
* Предлагать **льготную или бесплатную техническую поддержку** клиентам с высоким риском оттока.
* Внедрить **программу лояльности для долгосрочных клиентов**.
* Предлагать **семейные пакеты услуг**, повышающие ценность договора для семейных клиентов.

**Для улучшения модели:**
* Добавить временные признаки (сезонность расторжений, динамику активности пользователей).
* Рассмотреть дополнительные признаки о поведении клиентов (например, частоту обращений в техподдержку).
* Экспериментировать с архитектурами моделей и гиперпараметрами.
