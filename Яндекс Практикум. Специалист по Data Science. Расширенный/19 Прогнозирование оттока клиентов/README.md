## Описание проекта
Оператор связи сталкивается с проблемой оттока клиентов. В рамках проекта была разработана модель машинного обучения, позволяющая заранее определить клиентов с высоким риском расторжения договора на основе данных об услугах, платежах и характеристиках абонентов.

## Цель проекта
Построить модель, способную прогнозировать вероятность ухода клиента и выявлять пользователей с высоким риском оттока.<br>
Основная метрика качества — **ROC-AUC ≥ 0.85**.

## Результаты
* Проведен анализ данных и сформирован портрет клиента с высокой вероятностью ухода.
* Обучены и сравнены несколько моделей: **RandomForestClassifier**, **LGBMClassifier** и **KerasClassifier**.
* Лучшую предсказательную способность показала **LGBMClassifier** с метрикой **ROC-AUC = 0.908** на тестовой выборке.
* Наиболее важными признаками для прогноза оказались: длительность контракта, общие расходы клиента, ежемесячные расходы и наличие интернет-подключения.

## Рекомендации
**Бизнесу:**
* Сосредоточить внимание на клиентах с высоким риском расторжения, основываясь на предсказанной вероятности.
* Предлагать промокоды, специальные условия и дополнительные услуги тем, кто наиболее вероятно расторгнет договор.
* Переводить клиентов на помесячную оплату, чтобы снизить риск расторжения.
* Для клиентов с высоким риском разрыва договора предлагать бесплатные или льготные услуги выделенной линии технической поддержки.
* Для "старых" клиентов внедрить систему лояльности, чтобы удерживать их дольше.
* Для семейных клиентов предлагать семейные подписки или пакеты услуг, повышающие ценность договора.

**Для улучшения модели:**
* Добавить временные признаки (сезонность расторжений, активность пользователя).
* Рассмотреть дополнительные признаки о поведении клиентов, например, частоту обращений в техподдержку.
* Экспериментировать с архитектурой моделей, регуляризацией и гиперпараметрами для повышения качества предсказаний.
